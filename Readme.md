Weather App

A simple weather app built using HTML, CSS, and JavaScript. It lets you search for any city and shows the current temperature, weather condition, humidity, and wind speed.

Features
Search weather by city name
Shows temperature in °C
Shows weather condition (e.g. Clear, Rain, Clouds)
Shows humidity percentage
Shows wind speed
Displays "City not found" message for invalid city names
Displays an error message if something goes wrong (e.g. no internet)
Tech Used
HTML - for structure
CSS - for styling
JavaScript - for fetching and displaying weather data
OpenWeatherMap API - for weather data
